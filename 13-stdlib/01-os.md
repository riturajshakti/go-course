# 13.1 — os: Files, Args, and Environment

## What You'll Learn

- `os.Args`, the environment functions, and that `os.Exit` skips every pending `defer`
- `Open`/`Create`/`OpenFile` with the full `O_` flag set, and what the perm argument really does
- `FileInfo`, `os.FileMode` as a bit set, `ReadDir` and `DirEntry`
- Why `os.IsNotExist` is deprecated and `errors.Is(err, fs.ErrNotExist)` is not

## Coming From Another Language

| Other | Go |
|---|---|
| Node `process.argv` (argv[0]=node, argv[1]=script) | `os.Args[0]` is the program itself; flags start at `os.Args[1]` |
| Python `os.environ["K"]` raising `KeyError` | `os.Getenv` returns `""`; `os.LookupEnv` gives you the `(value, ok)` |
| Node `fs.readFileSync` throwing | `os.ReadFile` returns `([]byte, error)` — no exceptions anywhere |
| Python `open(p)` / Rust `File::open` | `os.Open` is **read-only**; use `os.OpenFile` for anything else |
| Rust `std::io::ErrorKind::NotFound` | `errors.Is(err, fs.ErrNotExist)` against a `*fs.PathError` |
| `process.exit()` running `finally` blocks | `os.Exit` runs **no** deferred functions at all |

`os` is a thin, almost unabstracted layer over POSIX syscalls. Every failing call returns
a `*fs.PathError` carrying the operation name, the path, and the raw `syscall.Errno` —
which is why you match on sentinels with `errors.Is` rather than on strings, and pull the
structured fields out with `errors.As`. The other Go-specific habit: nothing throws, so a
file handle is only closed if you `defer f.Close()` yourself, and `os.Exit` bypasses those
defers entirely. Note that most of the error and file-metadata types actually live in
`io/fs` and are only aliased into `os` — `os.FileInfo` *is* `fs.FileInfo`.

## os.Args

`os.Args` is a plain `[]string`. Index 0 is the executable path as invoked, not the
interpreter, and never your first flag.

```go
package main

import (
  "fmt"
  "os"
)

func main() {
  fmt.Println("len:", len(os.Args))
  fmt.Println("prog:", os.Args[0])
  fmt.Println("rest:", os.Args[1:])
}
```

Built as `./prog` and run as `./prog serve --port 8080 -v`. Output:

```
len: 5
prog: ./prog
rest: [serve --port 8080 -v]
```

`os.Args[1:]` is the conventional starting point, and it is exactly what `flag.Parse`
consumes (13.11). Use `go build` rather than `go run` when you care about `os.Args[0]` —
`go run` builds to a temporary directory and `Args[0]` becomes that temp path.

## The environment

| Function | Signature | Returns / note |
|---|---|---|
| `Getenv` | `(key string) string` | `""` for both unset and set-but-empty |
| `LookupEnv` | `(key string) (string, bool)` | the `ok` distinguishes unset from empty |
| `Setenv` | `(key, value string) error` | process-wide; errors on a key containing `=` or NUL |
| `Unsetenv` | `(key string) error` | removes the variable |
| `Environ` | `() []string` | snapshot of `"KEY=VALUE"` strings |
| `Clearenv` | `()` | deletes everything; no return |
| `ExpandEnv` | `(s string) string` | `$VAR` and `${VAR}`; unset expands to `""` |
| `Expand` | `(s string, mapping func(string) string) string` | `ExpandEnv` with your own lookup |

```go
package main

import (
  "fmt"
  "os"
  "strings"
)

func main() {
  os.Setenv("APP_PORT", "8080")
  os.Setenv("APP_DEBUG", "")

  fmt.Printf("Getenv set:     %q\n", os.Getenv("APP_PORT"))
  fmt.Printf("Getenv empty:   %q\n", os.Getenv("APP_DEBUG"))
  fmt.Printf("Getenv missing: %q\n", os.Getenv("APP_NOPE"))

  v, ok := os.LookupEnv("APP_PORT")
  fmt.Printf("LookupEnv set:     %q %v\n", v, ok)
  v, ok = os.LookupEnv("APP_DEBUG")
  fmt.Printf("LookupEnv empty:   %q %v\n", v, ok)
  v, ok = os.LookupEnv("APP_NOPE")
  fmt.Printf("LookupEnv missing: %q %v\n", v, ok)

  fmt.Println("Unsetenv:", os.Unsetenv("APP_PORT"))
  _, ok = os.LookupEnv("APP_PORT")
  fmt.Println("after Unsetenv, present:", ok)

  fmt.Println(os.ExpandEnv("listening on :${APP_LISTEN} as $APP_USER (missing: $NOPE)"))

  os.Setenv("APP_LISTEN", "9090")
  os.Setenv("APP_USER", "svc")
  fmt.Println(os.ExpandEnv("listening on :${APP_LISTEN} as $APP_USER (missing: $NOPE)"))

  fmt.Println(os.Expand("hi $NAME", func(k string) string { return "<" + k + ">" }))

  n := 0
  for _, kv := range os.Environ() {
    if strings.HasPrefix(kv, "APP_") {
      fmt.Println("environ:", kv)
      n++
    }
  }
  fmt.Println("APP_ vars:", n)

  err := os.Setenv("BAD=KEY", "x")
  fmt.Println("Setenv bad key:", err)
}
```

Output:

```
Getenv set:     "8080"
Getenv empty:   ""
Getenv missing: ""
LookupEnv set:     "8080" true
LookupEnv empty:   "" true
LookupEnv missing: "" false
Unsetenv: <nil>
after Unsetenv, present: false
listening on : as  (missing: )
listening on :9090 as svc (missing: )
hi <NAME>
environ: APP_DEBUG=
environ: APP_LISTEN=9090
environ: APP_USER=svc
APP_ vars: 3
Setenv bad key: setenv: invalid argument
```

`Getenv("APP_DEBUG")` and `Getenv("APP_NOPE")` are indistinguishable — both `""`. That
matters for any boolean-ish flag where "set to empty" and "not set" should behave
differently.

Idiomatic: `LookupEnv` when a default matters, `Getenv` when `""` is a fine default.

`Environ` returns a snapshot, so splitting on the *first* `=` is required — values may
contain `=`, keys may not.

```go
package main

import (
  "fmt"
  "os"
  "strings"
)

func main() {
  os.Clearenv()
  os.Setenv("A", "1")
  os.Setenv("CONN", "host=db port=5432")

  for _, kv := range os.Environ() {
    k, v, _ := strings.Cut(kv, "=")
    fmt.Printf("%q -> %q\n", k, v)
  }
  fmt.Println("total:", len(os.Environ()))
}
```

Output:

```
"A" -> "1"
"CONN" -> "host=db port=5432"
total: 2
```

`os.Clearenv` wipes the whole environment for the process and anything it later spawns.
It is a test-setup tool, not a production one.

## os.Exit skips defers

```go
package main

import (
  "fmt"
  "os"
)

func cleanup() {
  fmt.Println("cleanup ran")
}

func main() {
  defer cleanup()
  defer fmt.Println("second defer")
  fmt.Println("working")
  os.Exit(3)
}
```

Output (the `exit status 3` line is `go run` reporting the code, on stderr):

```
working
exit status 3
```

Neither defer ran. No "cleanup ran", no "second defer". `os.Exit` calls the exit syscall
immediately — it does not unwind the stack, so buffered writers are not flushed, temp
files are not removed, and `recover` never happens. This is the opposite of `panic`,
which runs every defer on the way out (3.5, 3.6).

The standard shape for a program that needs both a nonzero exit code and working defers is
to keep `main` trivial:

```go
package main

import (
  "fmt"
  "os"
)

func run() error {
  defer fmt.Println("cleanup ran")
  return fmt.Errorf("config missing")
}

func main() {
  if err := run(); err != nil {
    fmt.Fprintln(os.Stderr, "error:", err)
    os.Exit(1)
  }
}
```

Output:

```
cleanup ran
error: config missing
exit status 1
```

`run` returns normally, so its defers fire; only then does `main` exit. Idiomatic: `main`
does nothing but call `run()` and translate an error into an exit code.

## Stdin, Stdout, Stderr are *os.File

They are ordinary files, not a special stream type, so every `*os.File` method and every
`io.Writer`/`io.Reader` helper works on them.

```go
package main

import (
  "fmt"
  "os"
)

func main() {
  fmt.Printf("%T %T %T\n", os.Stdin, os.Stdout, os.Stderr)
  fmt.Println(os.Stdin.Name(), os.Stdout.Name(), os.Stderr.Name())
  fmt.Println(os.Stdout.Fd(), os.Stderr.Fd())

  os.Stdout.WriteString("direct to stdout\n")
  fmt.Fprintln(os.Stderr, "this line goes to stderr")

  fi, err := os.Stdin.Stat()
  if err != nil {
    fmt.Println("stat err:", err)
    return
  }
  fmt.Println("stdin is a pipe:", fi.Mode()&os.ModeCharDevice == 0)
}
```

Run as `echo hi | go run .`. Output:

```
*os.File *os.File *os.File
/dev/stdin /dev/stdout /dev/stderr
1 2
direct to stdout
this line goes to stderr
stdin is a pipe: true
```

The `ModeCharDevice` test is the standard "am I being piped to or is this a terminal?"
check — a tty is a character device, a pipe is not. Run the same program without the pipe
and the last line prints `false`.

## Opening files

| Function | Signature | Note |
|---|---|---|
| `Open` | `(name string) (*File, error)` | **read-only**; `O_RDONLY` |
| `Create` | `(name string) (*File, error)` | `O_RDWR\|O_CREATE\|O_TRUNC`, perm `0666` |
| `OpenFile` | `(name string, flag int, perm FileMode) (*File, error)` | the general form |
| `ReadFile` | `(name string) ([]byte, error)` | opens, reads all, closes |
| `WriteFile` | `(name string, data []byte, perm FileMode) error` | creates or truncates |
| `CreateTemp` | `(dir, pattern string) (*File, error)` | `*` in pattern is the random part |
| `MkdirTemp` | `(dir, pattern string) (string, error)` | returns the directory name |

The `O_` flags, combined with `|`:

| Flag | Meaning |
|---|---|
| `os.O_RDONLY` | read only (the zero value — it is `0`) |
| `os.O_WRONLY` | write only |
| `os.O_RDWR` | read and write |
| `os.O_APPEND` | every write goes to the end, atomically |
| `os.O_CREATE` | create if absent — the only flag that uses `perm` |
| `os.O_EXCL` | with `O_CREATE`, fail if the file exists |
| `os.O_TRUNC` | truncate to zero length on open |
| `os.O_SYNC` | writes block until flushed to the device |

Exactly one of `O_RDONLY`/`O_WRONLY`/`O_RDWR` is required. `perm` is only consulted when
`O_CREATE` actually creates the file, and the result is `perm &^ umask` — so `0666` with
the usual `022` umask lands as `0644`.

```go
package main

import (
  "fmt"
  "os"
)

func main() {
  dir, err := os.MkdirTemp("", "oslesson")
  if err != nil {
    panic(err)
  }
  defer os.RemoveAll(dir)
  if err := os.Chdir(dir); err != nil {
    panic(err)
  }

  if err := os.WriteFile("notes.txt", []byte("line one\nline two\n"), 0o644); err != nil {
    panic(err)
  }
  data, err := os.ReadFile("notes.txt")
  fmt.Printf("ReadFile: %d bytes, err=%v\n%s", len(data), err, data)

  f, err := os.Create("created.txt")
  fmt.Println("Create err:", err)
  n, err := f.WriteString("hello")
  fmt.Println("WriteString:", n, err)
  fmt.Println("Close:", f.Close())

  r, err := os.Open("notes.txt")
  if err != nil {
    panic(err)
  }
  buf := make([]byte, 8)
  n, err = r.Read(buf)
  fmt.Printf("Read: n=%d err=%v %q\n", n, err, buf[:n])
  off, err := r.Seek(9, 0)
  fmt.Println("Seek:", off, err)
  n, err = r.Read(buf)
  fmt.Printf("Read: n=%d err=%v %q\n", n, err, buf[:n])
  at := make([]byte, 4)
  n, err = r.ReadAt(at, 0)
  fmt.Printf("ReadAt: n=%d err=%v %q\n", n, err, at[:n])
  r.Close()

  ap, err := os.OpenFile("notes.txt", os.O_APPEND|os.O_WRONLY, 0o644)
  if err != nil {
    panic(err)
  }
  ap.WriteString("appended\n")
  ap.Close()
  data, _ = os.ReadFile("notes.txt")
  fmt.Printf("after append:\n%s", data)

  excl, err := os.OpenFile("notes.txt", os.O_CREATE|os.O_EXCL|os.O_WRONLY, 0o644)
  fmt.Println("O_EXCL on existing:", excl == nil, err)

  if err := os.Truncate("notes.txt", 8); err != nil {
    panic(err)
  }
  data, _ = os.ReadFile("notes.txt")
  fmt.Printf("after Truncate(8): %q\n", data)

  fmt.Println("Rename:", os.Rename("created.txt", "renamed.txt"))
  fmt.Println("Remove:", os.Remove("renamed.txt"))

  tmp, err := os.CreateTemp("", "upload-*.bin")
  fmt.Println("CreateTemp err:", err)
  fmt.Println("CreateTemp has prefix/suffix:", tmp != nil)
  tmp.Close()
  os.Remove(tmp.Name())

  fmt.Println("MkdirAll:", os.MkdirAll("a/b/c", 0o755))
  fmt.Println("Mkdir existing:", os.Mkdir("a", 0o755) != nil)
  fmt.Println("Mkdir deep without parents:", os.Mkdir("x/y", 0o755) != nil)
}
```

Output:

```
ReadFile: 18 bytes, err=<nil>
line one
line two
Create err: <nil>
WriteString: 5 <nil>
Close: <nil>
Read: n=8 err=<nil> "line one"
Seek: 9 <nil>
Read: n=8 err=<nil> "line two"
ReadAt: n=4 err=<nil> "line"
after append:
line one
line two
appended
O_EXCL on existing: true open notes.txt: file exists
after Truncate(8): "line one"
Rename: <nil>
Remove: <nil>
CreateTemp err: <nil>
CreateTemp has prefix/suffix: true
MkdirAll: <nil>
Mkdir existing: true
Mkdir deep without parents: true
```

Three things worth pulling out. `ReadAt` reads at an absolute offset and does **not** move
the file position, so it is the concurrency-safe read primitive. `O_CREATE|O_EXCL` is the
atomic "create a lock file or fail" idiom — the check and the create are one syscall.
`os.Mkdir` fails both when the directory exists and when a parent is missing; `MkdirAll`
succeeds in both cases, which is why it is what you almost always want.

`os.Remove` deletes one file or one *empty* directory. `os.RemoveAll` deletes a tree and —
unlike `Remove` — returns `nil` when the path was already gone.

## FileInfo, FileMode, and permissions

`Stat` follows symlinks; `Lstat` reports on the link itself.

| `FileInfo` method | Returns |
|---|---|
| `Name() string` | base name only, no directory |
| `Size() int64` | bytes; meaningless for directories |
| `Mode() FileMode` | type bits plus permission bits |
| `ModTime() time.Time` | last modification |
| `IsDir() bool` | shorthand for `Mode().IsDir()` |
| `Sys() any` | the underlying `*syscall.Stat_t` |

| `FileMode` bit | Meaning |
|---|---|
| `ModeDir` (`d`) | directory |
| `ModeSymlink` (`L`) | symbolic link |
| `ModeNamedPipe` (`p`) | FIFO |
| `ModeSocket` (`S`) | Unix domain socket |
| `ModeDevice` (`D`) | device file |
| `ModeCharDevice` (`c`) | character device (with `ModeDevice`) |
| `ModeSetuid` (`u`) / `ModeSetgid` (`g`) | setuid / setgid |
| `ModeSticky` (`t`) | sticky bit |
| `ModeIrregular` (`?`) | nothing else fits |
| `ModePerm` (`0777`) | mask for just the permission bits |

| `FileMode` method | Returns |
|---|---|
| `IsDir() bool` | `ModeDir` set |
| `IsRegular() bool` | no type bits set at all |
| `Perm() FileMode` | `m & ModePerm` — permissions only |
| `Type() FileMode` | `m & ModeType` — type bits only |
| `String() string` | the `drwxr-xr-x` form |

```go
package main

import (
  "fmt"
  "os"
  "time"
)

func main() {
  dir, _ := os.MkdirTemp("", "oslesson")
  defer os.RemoveAll(dir)
  os.Chdir(dir)

  os.WriteFile("data.txt", []byte("0123456789"), 0o644)
  os.Mkdir("sub", 0o755)
  os.WriteFile("script.sh", []byte("#!/bin/sh\n"), 0o755)
  os.WriteFile("secret", []byte("x"), 0o600)
  os.Symlink("data.txt", "link.txt")

  fi, err := os.Stat("data.txt")
  fmt.Println("err:", err)
  fmt.Println("Name:", fi.Name())
  fmt.Println("Size:", fi.Size())
  fmt.Println("Mode:", fi.Mode())
  fmt.Println("IsDir:", fi.IsDir())
  fmt.Println("ModTime recent:", time.Since(fi.ModTime()) < time.Minute)

  for _, name := range []string{"data.txt", "sub", "script.sh", "secret", "link.txt"} {
    st, _ := os.Stat(name)
    ls, _ := os.Lstat(name)
    fmt.Printf("%-10s stat=%-12v lstat=%-12v perm=%v dir=%v\n",
      name, st.Mode(), ls.Mode(), st.Mode().Perm(), st.IsDir())
  }

  m := os.FileMode(0o755) | os.ModeDir
  fmt.Println("constructed:", m, m.IsDir(), m.IsRegular(), m.Perm(), uint32(m.Perm()))
  fmt.Printf("octal: %o  %#o  string: %s\n", fi.Mode().Perm(), fi.Mode().Perm(), fi.Mode())

  fmt.Println("Chmod:", os.Chmod("secret", 0o640))
  st, _ := os.Stat("secret")
  fmt.Println("after Chmod:", st.Mode())
}
```

Output:

```
err: <nil>
Name: data.txt
Size: 10
Mode: -rw-r--r--
IsDir: false
ModTime recent: true
data.txt   stat=-rw-r--r--   lstat=-rw-r--r--   perm=-rw-r--r-- dir=false
sub        stat=drwxr-xr-x   lstat=drwxr-xr-x   perm=-rwxr-xr-x dir=true
script.sh  stat=-rwxr-xr-x   lstat=-rwxr-xr-x   perm=-rwxr-xr-x dir=false
secret     stat=-rw-------   lstat=-rw-------   perm=-rw------- dir=false
link.txt   stat=-rw-r--r--   lstat=Lrwxr-xr-x   perm=-rw-r--r-- dir=false
constructed: drwxr-xr-x true false -rwxr-xr-x 493
octal: 644  0644  string: -rw-r--r--
```

followed by:

```
Chmod: <nil>
after Chmod: -rw-r-----
```

`link.txt` is the row to read: `Stat` reports the *target* (`-rw-r--r--`, a regular file)
while `Lstat` reports the link (`Lrwxr-xr-x`, the `L` being `ModeSymlink`). Printing a
`FileMode` always shows ten characters — type bit first, then `rwxrwxrwx` — so
`Perm()` on a directory still prints a leading `-` because the type bits were masked off.

Always write permissions as `0o644`, never `644`. Decimal `644` is `0o1204`, which is
silently wrong.

## ReadDir and DirEntry

`os.ReadDir` returns `[]fs.DirEntry` sorted by filename. A `DirEntry` is cheaper than a
`FileInfo` because the name and type usually come straight out of the directory read
without a second `stat`.

| `DirEntry` method | Returns |
|---|---|
| `Name() string` | base name |
| `IsDir() bool` | from the directory entry's type |
| `Type() FileMode` | type bits only — no permission bits |
| `Info() (FileInfo, error)` | the full stat; may hit the disk |

```go
package main

import (
  "fmt"
  "os"
)

func main() {
  dir, _ := os.MkdirTemp("", "oslesson")
  defer os.RemoveAll(dir)
  os.Chdir(dir)

  os.WriteFile("data.txt", []byte("0123456789"), 0o644)
  os.Mkdir("sub", 0o755)
  os.WriteFile("script.sh", []byte("#!/bin/sh\n"), 0o755)
  os.WriteFile("secret", []byte("x"), 0o600)
  os.Symlink("data.txt", "link.txt")

  ents, err := os.ReadDir(".")
  fmt.Println("ReadDir err:", err)
  for _, e := range ents {
    info, _ := e.Info()
    fmt.Printf("%-10s IsDir=%-5v Type=%-12v size=%d\n", e.Name(), e.IsDir(), e.Type(), info.Size())
  }
}
```

Output:

```
ReadDir err: <nil>
data.txt   IsDir=false Type=----------   size=10
link.txt   IsDir=false Type=L---------   size=8
script.sh  IsDir=false Type=----------   size=10
secret     IsDir=false Type=----------   size=1
sub        IsDir=true  Type=d---------   size=64
```

`Type()` has the permission bits masked out, which is why a regular file shows as ten
dashes. Note `Info()` on `link.txt` used `Lstat` semantics — size 8 is the length of the
target *name*, not the target's contents. For walking a whole tree use `filepath.WalkDir`
(13.10), which is built on `ReadDir` and avoids reading an entire directory into memory.

## Errors: *fs.PathError

Every path-based failure returns a `*fs.PathError`. Compare against the `fs.Err*`
sentinels with `errors.Is`, and reach for the fields with `errors.As` (8.3).

| Sentinel | Raised by |
|---|---|
| `fs.ErrNotExist` | `ENOENT` — missing file or missing parent directory |
| `fs.ErrExist` | `EEXIST` — and, on darwin, `ENOTEMPTY` |
| `fs.ErrPermission` | `EACCES`, `EPERM` |
| `fs.ErrClosed` | operating on an already-closed `*os.File` |
| `fs.ErrInvalid` | a nil or invalid argument |

```go
package main

import (
  "errors"
  "fmt"
  "io/fs"
  "os"
)

func describe(label string, err error) {
  fmt.Printf("%s\n", label)
  fmt.Printf("  err:          %v\n", err)
  fmt.Printf("  type:         %T\n", err)
  var pe *fs.PathError
  if errors.As(err, &pe) {
    fmt.Printf("  Op=%q Path=%q Err=%v\n", pe.Op, pe.Path, pe.Err)
  }
  fmt.Printf("  ErrNotExist:  %v\n", errors.Is(err, fs.ErrNotExist))
  fmt.Printf("  ErrPermission:%v\n", errors.Is(err, fs.ErrPermission))
  fmt.Printf("  ErrExist:     %v\n", errors.Is(err, fs.ErrExist))
}

func main() {
  dir, _ := os.MkdirTemp("", "oslesson")
  defer func() {
    os.Chmod(dir+"/ro.txt", 0o644)
    os.RemoveAll(dir)
  }()
  os.Chdir(dir)

  _, err := os.Open("no-such-file.txt")
  describe("os.Open on a missing file:", err)

  os.WriteFile("ro.txt", []byte("x"), 0o444)
  _, err = os.OpenFile("ro.txt", os.O_WRONLY, 0o444)
  describe("os.OpenFile O_WRONLY on a read-only file:", err)

  os.Mkdir("full", 0o755)
  os.WriteFile("full/child", []byte("x"), 0o644)
  err = os.Remove("full")
  describe("os.Remove on a non-empty directory:", err)

  _, err = os.ReadFile("nope/deeper.txt")
  describe("os.ReadFile through a missing directory:", err)

  fmt.Println("RemoveAll on non-empty:", os.RemoveAll("full"))
  fmt.Println("Remove on already-gone:", os.Remove("full"))
  fmt.Println("RemoveAll on already-gone:", os.RemoveAll("full"))
}
```

Output:

```
os.Open on a missing file:
  err:          open no-such-file.txt: no such file or directory
  type:         *fs.PathError
  Op="open" Path="no-such-file.txt" Err=no such file or directory
  ErrNotExist:  true
  ErrPermission:false
  ErrExist:     false
os.OpenFile O_WRONLY on a read-only file:
  err:          open ro.txt: permission denied
  type:         *fs.PathError
  Op="open" Path="ro.txt" Err=permission denied
  ErrNotExist:  false
  ErrPermission:true
  ErrExist:     false
os.Remove on a non-empty directory:
  err:          remove full: directory not empty
  type:         *fs.PathError
  Op="remove" Path="full" Err=directory not empty
  ErrNotExist:  false
  ErrPermission:false
  ErrExist:     true
os.ReadFile through a missing directory:
  err:          open nope/deeper.txt: no such file or directory
  type:         *fs.PathError
  Op="open" Path="nope/deeper.txt" Err=no such file or directory
  ErrNotExist:  true
  ErrPermission:false
  ErrExist:     false
RemoveAll on non-empty: <nil>
Remove on already-gone: remove full: no such file or directory
RemoveAll on already-gone: <nil>
```

Two real surprises in there. "directory not empty" (`ENOTEMPTY`) matches
`fs.ErrExist`, not some dedicated sentinel — so an `errors.Is(err, fs.ErrExist)` branch
written to mean "the file already exists" will also catch a failed directory removal.
And a missing *parent* directory and a missing *file* give the identical `ENOENT`, so
`fs.ErrNotExist` cannot tell you which part of the path was absent; read `pe.Path` if you
need to say.

`pe.Err` is the bare `syscall.Errno`, so `errors.Is(err, syscall.ENOTEMPTY)` works too
when you need the exact errno rather than the portable sentinel.

### Why os.IsNotExist is deprecated

```go
package main

import (
  "errors"
  "fmt"
  "io/fs"
  "os"
)

func main() {
  _, raw := os.Open("missing.txt")
  wrapped := fmt.Errorf("loading config: %w", raw)

  fmt.Println("os.IsNotExist(raw):      ", os.IsNotExist(raw))
  fmt.Println("os.IsNotExist(wrapped):  ", os.IsNotExist(wrapped))
  fmt.Println("errors.Is(raw, ...):     ", errors.Is(raw, fs.ErrNotExist))
  fmt.Println("errors.Is(wrapped, ...): ", errors.Is(wrapped, fs.ErrNotExist))
  fmt.Println("os.ErrNotExist == fs.ErrNotExist:", os.ErrNotExist == fs.ErrNotExist)
  fmt.Println(wrapped)
}
```

Output:

```
os.IsNotExist(raw):       true
os.IsNotExist(wrapped):   false
errors.Is(raw, ...):      true
errors.Is(wrapped, ...):  true
os.ErrNotExist == fs.ErrNotExist: true
loading config: open missing.txt: no such file or directory
```

That `false` on line two is the whole story: `os.IsNotExist` predates error wrapping and
does not unwrap, so it silently stops working the moment any layer adds context with
`%w`. `errors.Is` walks the chain. `os.ErrNotExist` is just an alias for
`fs.ErrNotExist`, so either name works as the target.

Idiomatic: `errors.Is(err, fs.ErrNotExist)`, always.

## Process and host information

| Function | Signature | Note |
|---|---|---|
| `Getwd` | `() (string, error)` | absolute current directory |
| `Chdir` | `(dir string) error` | process-wide; hostile to concurrent tests |
| `Hostname` | `() (string, error)` | |
| `Getpid` / `Getppid` | `() int` | no error return |
| `Getuid` / `Geteuid` / `Getgid` / `Getegid` | `() int` | `-1` on Windows |
| `Executable` | `() (string, error)` | path to the running binary |
| `UserHomeDir` | `() (string, error)` | `$HOME` |
| `UserCacheDir` / `UserConfigDir` | `() (string, error)` | XDG-ish, platform-specific |
| `TempDir` | `() string` | `$TMPDIR`; no error |
| `Getpagesize` | `() int` | |

```go
package main

import (
  "fmt"
  "os"
  "path/filepath"
)

func main() {
  wd, err := os.Getwd()
  fmt.Println("Getwd err:", err, "absolute:", filepath.IsAbs(wd))

  dir, _ := os.MkdirTemp("", "oslesson")
  defer os.RemoveAll(dir)
  fmt.Println("Chdir:", os.Chdir(dir))
  now, _ := os.Getwd()
  fmt.Println("changed:", now != wd)

  h, err := os.Hostname()
  fmt.Println("Hostname non-empty:", h != "", err)
  fmt.Println("Getpid > 0:", os.Getpid() > 0)
  fmt.Println("Getppid > 0:", os.Getppid() > 0)
  fmt.Println("Getuid >= 0:", os.Getuid() >= 0)

  home, err := os.UserHomeDir()
  fmt.Println("UserHomeDir abs:", filepath.IsAbs(home), err)
  cache, err := os.UserCacheDir()
  fmt.Println("UserCacheDir abs:", filepath.IsAbs(cache), err)
  cfg, err := os.UserConfigDir()
  fmt.Println("UserConfigDir abs:", filepath.IsAbs(cfg), err)

  exe, err := os.Executable()
  fmt.Println("Executable abs:", filepath.IsAbs(exe), err)
  fmt.Println("TempDir non-empty:", os.TempDir() != "")
}
```

The actual hostname, pids and home directory are machine-specific, so this program prints
assertions about them rather than the values. Output:

```
Getwd err: <nil> absolute: true
Chdir: <nil>
changed: true
Hostname non-empty: true <nil>
Getpid > 0: true
Getppid > 0: true
Getuid >= 0: true
UserHomeDir abs: true <nil>
UserCacheDir abs: true <nil>
UserConfigDir abs: true <nil>
Executable abs: true <nil>
TempDir non-empty: true
```

`os.Chdir` changes state for the entire process, including every goroutine. In tests
prefer `t.TempDir()` with absolute paths over `Chdir`; parallel tests that `Chdir` will
corrupt each other.

## A complete program: atomic file replacement

Writing in place truncates the file before the new content lands, so a crash leaves it
empty. Write to a temp file in the *same* directory and `Rename` over the target —
`rename(2)` is atomic within a filesystem.

```go
package main

import (
  "fmt"
  "os"
  "path/filepath"
)

func writeAtomic(path string, data []byte, perm os.FileMode) error {
  tmp, err := os.CreateTemp(filepath.Dir(path), filepath.Base(path)+".tmp-*")
  if err != nil {
    return err
  }
  name := tmp.Name()
  defer os.Remove(name)

  if _, err := tmp.Write(data); err != nil {
    tmp.Close()
    return err
  }
  if err := tmp.Sync(); err != nil {
    tmp.Close()
    return err
  }
  if err := tmp.Close(); err != nil {
    return err
  }
  if err := os.Chmod(name, perm); err != nil {
    return err
  }
  return os.Rename(name, path)
}

func main() {
  dir, _ := os.MkdirTemp("", "oslesson")
  defer os.RemoveAll(dir)
  target := filepath.Join(dir, "config.json")

  fmt.Println("write 1:", writeAtomic(target, []byte(`{"v":1}`), 0o600))
  data, _ := os.ReadFile(target)
  st, _ := os.Stat(target)
  fmt.Printf("content=%s mode=%v\n", data, st.Mode())

  fmt.Println("write 2:", writeAtomic(target, []byte(`{"v":2}`), 0o644))
  data, _ = os.ReadFile(target)
  st, _ = os.Stat(target)
  fmt.Printf("content=%s mode=%v\n", data, st.Mode())

  ents, _ := os.ReadDir(dir)
  fmt.Println("leftover files:", len(ents))
}
```

Output:

```
write 1: <nil>
content={"v":1} mode=-rw-------
write 2: <nil>
content={"v":2} mode=-rw-r--r--
leftover files: 1
```

The `defer os.Remove(name)` cleans up the temp file on every error path and harmlessly
fails after a successful rename. `Sync` is what makes the durability claim real — without
it the data may still be in the page cache when the rename commits. `CreateTemp` always
makes the file `0600`, hence the explicit `Chmod`.

## Quick Reference

| Need | Call |
|---|---|
| Command-line arguments | `os.Args[1:]` |
| Env var with a default | `v, ok := os.LookupEnv(k)` |
| Read a whole file | `os.ReadFile(name)` |
| Write a whole file | `os.WriteFile(name, data, 0o644)` |
| Open for reading | `os.Open(name)` |
| Open for appending | `os.OpenFile(n, os.O_APPEND\|os.O_WRONLY\|os.O_CREATE, 0o644)` |
| Create or fail if present | `os.OpenFile(n, os.O_CREATE\|os.O_EXCL\|os.O_WRONLY, 0o644)` |
| Truncate and rewrite | `os.Create(name)` |
| Does it exist? | `_, err := os.Stat(n); errors.Is(err, fs.ErrNotExist)` |
| Is it a directory? | `fi.IsDir()` |
| Permission bits | `fi.Mode().Perm()` |
| List a directory | `os.ReadDir(".")` |
| Make a directory tree | `os.MkdirAll(p, 0o755)` |
| Temp file / temp dir | `os.CreateTemp("", "p-*")` / `os.MkdirTemp("", "p")` |
| Delete a file | `os.Remove(n)` |
| Delete a tree | `os.RemoveAll(p)` |
| Exit with a code | `os.Exit(1)` from `main` only |
| Extract Op/Path from an error | `var pe *fs.PathError; errors.As(err, &pe)` |

| Trap | Reality |
|---|---|
| `os.Exit` in a function with defers | the defers never run |
| `os.Open` for writing | read-only; use `os.OpenFile` |
| `0644` without the `0o` | that is decimal 644 = `0o1204` |
| `os.IsNotExist(wrappedErr)` | always `false`; use `errors.Is` |
| `os.Getenv` to detect "unset" | indistinguishable from empty; use `LookupEnv` |
| `perm` on an existing file | ignored entirely; only `O_CREATE` uses it |
| `os.Remove` on a directory with contents | `directory not empty`; use `RemoveAll` |
| `os.Chdir` in a parallel test | corrupts every other goroutine |

## Common Mistakes

**Calling `os.Exit` where cleanup is deferred.** Move the body into a `run() error` and
let `main` be the only place that exits.

**Writing file permissions as `644`.** Go has no implicit octal — write `0o644` or the
mode becomes nonsense.

**Using `os.IsNotExist` on an error you wrapped with `%w`.** It cannot unwrap; use
`errors.Is(err, fs.ErrNotExist)`.

**Treating `os.Getenv("FLAG") == ""` as "not configured".** A deliberately empty value is
also `""`; switch to `os.LookupEnv`.

**Forgetting `defer f.Close()` after `os.Open`.** Nothing is garbage-collected into a
close, and the file descriptor leaks until the process exits.

**Checking `os.Stat` for existence before opening.** Another process can change things in
between; just open the file and handle the error.
